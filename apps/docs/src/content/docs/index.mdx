import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components'

```ts
import { createAnalytics } from 'consentlayer'
import { ga4 } from 'consentlayer/providers/ga4'
import { meta } from 'consentlayer/providers/meta'

export const analytics = createAnalytics({
  providers: [ga4({ measurementId: 'G-XXXXXXX' }), meta({ pixelId: '123456789012345' })],
})

analytics.track('purchase', { transaction_id: 'o1', value: 30, currency: 'EUR' })
// GA4 receives `purchase` once analytics is granted; Meta receives `Purchase` once marketing is.
```

## Why consentlayer

<CardGrid>
  <Card title="Consent decides what loads" icon="approve-check">
    Each provider declares the category it needs: preferences, analytics,
    marketing or one of your own. Nothing loads before that category is
    granted, and withdrawing it stops the provider.
  </Card>
  <Card title="One event, every provider" icon="random">
    Track `purchase` or `sign_up` once. consentlayer translates it into the
    format of GA4, Meta, PostHog and the rest, with one event ID for
    deduplication.
  </Card>
  <Card title="Browser and server" icon="seti:json">
    One route forwards browser events to the Meta Conversions API, and
    webhooks send server-only events to GA4 and Meta.
  </Card>
  <Card title="Proof of consent" icon="document">
    Record every choice in your own Postgres, Supabase, Prisma, Drizzle or
    Redis database, and have your server trust only the consent you recorded.
  </Card>
  <Card title="Your banner, your design" icon="pencil">
    No UI ships with the package. Copy the banner recipe and restyle it, or
    build your own on `useConsentController()`.
  </Card>
  <Card title="Small by default" icon="rocket">
    The core is about 6 kB (brotli). Each provider, and heavy features such as
    session replay, load as separate chunks only when used.
  </Card>
</CardGrid>
