# consentlayer

Consent-first analytics for React and Next.js: one instance tracks to GA4, Meta
Pixel, PostHog, Sentry and more, and loads each provider only once the visitor
has agreed to its category.

**Docs: [consentlayer.vercel.app](https://consentlayer.vercel.app)**

```bash
pnpm add consentlayer
```
