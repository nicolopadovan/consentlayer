# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone taking part in its issues, pull requests and discussions is expected
to follow it.

Report unacceptable behavior to the maintainer privately, through the contact
on [their GitHub profile](https://github.com/nicolopadovan). Reports are
handled confidentially.
